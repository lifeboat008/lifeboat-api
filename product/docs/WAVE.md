# Lifeboat Wave application

As of 2026-10-08, all four Lifeboat repositories are public and MIT licensed. They have CONTRIBUTING and SECURITY guidance. These repositories have **not yet been applied to or approved by** the Stellar Wave Program. Lifeboat remains a testnet pilot; a Wave application does not authorize mainnet funds.

The organization owner must sign in at [Drips Wave](https://www.drips.network/wave/stellar), open **Maintainers → Orgs and Repos**, install the [Drips Wave GitHub App](https://github.com/apps/drips-wave) on `lifeboat008`, sync the four public repositories, and apply each relevant repository to the Stellar Wave Program. Program organizers decide approval. See [Drips' maintainer instructions](https://docs.drips.network/wave/maintainers/participating-in-a-wave/).

The following scoped issues are ready for contributors. **Add a Wave issue only after its repository is approved**, then set its complexity in the Drips app or apply the `Stellar Wave` label. The complexity suggestion is in each issue body.

| Repository | Issue |
| --- | --- |
| protocol | [Disputed claims and reviewer conflicts](https://github.com/lifeboat008/lifeboat-protocol/issues/1) |
| ledger | [Background payment reconciliation](https://github.com/lifeboat008/lifeboat-ledger/issues/1) |
| API | [Project-scoped actor authorization](https://github.com/lifeboat008/lifeboat-api/issues/1) |
| API | [Testnet treasury coverage checks](https://github.com/lifeboat008/lifeboat-api/issues/2) |
| GitHub adapter | [Installation suspension and removal](https://github.com/lifeboat008/lifeboat-github/issues/1) |
| GitHub adapter | [Auditable repository enrollment](https://github.com/lifeboat008/lifeboat-github/issues/2) |

During a Wave, maintainers must review applications, assign contributors, review pull requests, and merge accepted work promptly. A consenting-repository and sponsor pilot, custody and asset decisions, tenant isolation, and operational review still gate real-money use.
